# Currículo App

Aplicativo de currículo e portfólio desenvolvido para a cadeira de **Programação para Dispositivos Móveis**, na **UNICAP**, semestre **2026.2**, com o professor **Márcio Bueno**.

## Sobre o projeto

O app apresenta informações de perfil, formação acadêmica, experiência profissional e projetos. Os dados são carregados de uma API, e a tela de projetos permite filtrar os resultados por tecnologia.

## Tecnologias

- Expo e React Native
- JavaScript
- Expo Router
- API REST

## Como executar

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o Expo:

   ```bash
   npx expo start
   ```

3. Abra o projeto no Expo Go ou use a opção correspondente no terminal para executar no Android, iOS ou web.

## API

O aplicativo consulta o perfil na API configurada em `src/services/api.js`.
